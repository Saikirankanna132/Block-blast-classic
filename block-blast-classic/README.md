# 🧱 Block Blast Classic

A relaxing classic block puzzle game for **Android** and **iOS**, built with
**Flutter**. Drag blocks from the tray onto a 10×10 grid, complete rows or
columns to clear them, and chase your high score. No ads, fully offline,
family-friendly — designed to be comfortable for beginners and older adults.

## ✨ Features

- **Classic gameplay** — 10×10 board, drag & drop 3 blocks at a time
- **22 block shapes** — lines, squares, L/T/Z/S, plus, corners (weighted so
  big blocks get rarer as the board fills — always fair, never impossible)
- **Smart snapping** — block snaps to the nearest valid grid position,
  green/red highlight shows where it will land while dragging
- **Scoring** — +10 per square placed, +100 per cleared row/column,
  combo bonus for multi-line clears, floating score popups
- **Effects** — row-clear flash, combo celebration banner, gentle haptics
- **Sounds** — placement / clear / combo / game-over / click + looping
  background music, all with ON/OFF toggles (real `.wav` files included in
  `assets/sounds/`, not just placeholders)
- **High score & stats** — best score, games played, average score,
  blocks placed, rows/columns cleared — all stored locally on-device
- **Settings** — sound, music, vibration, dark mode, reset high score,
  language (English / తెలుగు / हिन्दी / Español)
- **Accessibility** — large-text mode, high-contrast palette,
  color-blind friendly mode (pattern dots on blocks), big 60px buttons
- **Offline** — zero network calls, works fully without internet

## 🛠️ Build instructions

### Option A — Free cloud build with GitHub Actions (no PC needed) ⭐

This project now includes a ready-made workflow
(`.github/workflows/build-apk.yml`):

1. Create a free GitHub account and a new repository.
2. Upload this entire project folder to the repo (web upload works fine).
3. Open the repo's **Actions** tab → **Build Android APK** → download the
   **BlockBlastClassic-apk** file from the finished run (takes ~5–10 min).
   You can also trigger it manually with **Run workflow**.
4. Copy the APK to your phone, tap it, allow "install unknown apps" —
   done. (It's signed with a debug key by CI, fine for personal use;
   for Play Store release, sign it with your own key.)

### Option B — PC / Mac

1. Install Flutter: https://docs.flutter.dev/get-started/install
   (Flutter 3.22+ / Dart 3.2+), plus Android Studio (Android SDK) and/or
   Xcode (iOS).
2. Open a terminal **inside this project folder**:
   ```bash
   flutter pub get
   dart run flutter_launcher_icons
   dart run flutter_native_splash:create
   ```
   (Platform folders `android/` and `ios/` are already included, so no
   `flutter create` step is needed. If you ever delete them, regenerate
   with `flutter create --org com.example.blockblast --project-name block_blast_classic .`.)
3. Run on a connected device / emulator:
   ```bash
   flutter run
   ```
4. Build release binaries:
   ```bash
   flutter build apk --release        # Android APK
   flutter build appbundle --release  # Android App Bundle (Play Store)
   flutter build ipa --release        # iOS (needs macOS + Xcode)
   ```
5. Run tests:
   ```bash
   flutter test
   ```

### Option C — Termux (on-device, Android)

> Building a full Flutter app purely inside Termux is **not officially
> supported** — the Flutter SDK expects a desktop OS. The practical
> on-device routes are:

1. **Easiest:** install a Linux distro in Termux via `proot-distro`
   (e.g. Ubuntu), then follow Option A inside it:
   ```bash
   pkg install proot-distro
   proot-distro install ubuntu
   proot-distro login ubuntu
   # then: apt update, install curl/git/unzip, download Flutter SDK,
   # flutter doctor, and continue from Option A step 2
   ```
   You still need the Android SDK for APK output; `flutter build apk`
   works once `ANDROID_HOME`/command-line tools are set up.
2. **Alternative:** use an online builder (Codemagic, GitHub Actions)
   with this source — push the folder to a repo and let CI produce
   the APK/AAB.

Either way, **no code changes are needed** — this project is a standard
Flutter app.

## 🎮 How to play

1. Tap **Start Game**.
2. Drag a block from the bottom tray onto the 10×10 board — it snaps
   into place (green highlight = fits, red = blocked).
3. Fill a whole row or column to blast it away for +100 points.
4. When all 3 tray blocks are used, 3 new ones appear.
5. Game ends when no remaining block fits anywhere. Beat your best!

## 💰 Monetization (optional)

Ads are **off by default** and there is no ad SDK in the project. To add
an optional rewarded ad ("one extra chance after Game Over"), add
`google_mobile_ads` to `pubspec.yaml`, show the reward prompt in the
game-over dialog in `game_screen.dart` (`_showGameOver`), and on reward
clear a 3×3 area of the board and set `gameOver = false`.
